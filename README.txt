SIMPLEVANILLA — сайт Minecraft-сервера

Файлы:
- index.html — структура и текст сайта
- style.css — оформление и адаптация для телефонов
- script.js — копирование IP и мобильное меню
- CNAME — домен для GitHub Pages

IP сервера: SimpleVanilla.ru-cc.ru
Версия: Minecraft Java 1.21.11

ПУБЛИКАЦИЯ НА GITHUB PAGES:
1. Создай публичный репозиторий на GitHub, например simplevanilla.
2. Загрузи ВСЕ файлы из этой папки в корень репозитория (не сам ZIP).
3. Открой Settings -> Pages.
4. В разделе Build and deployment выбери Deploy from a branch, branch main, folder /(root), нажми Save.
5. В Settings -> Pages укажи Custom domain: simplevanilla.ru и сохрани.
6. У регистратора домена настрой DNS:
   A @ -> 185.199.108.153
   A @ -> 185.199.109.153
   A @ -> 185.199.110.153
   A @ -> 185.199.111.153
   CNAME www -> ТВОЙ-НИК.github.io
   Замени ТВОЙ-НИК на свой username GitHub.
   Удали конфликтующие записи A/AAAA/CNAME для @ или www, если они мешают.
7. После проверки DNS включи Enforce HTTPS в Settings -> Pages.
DNS может обновляться до 24 часов. HTTPS-сертификат иногда появляется не сразу.

ВАЖНО:
- Домен simplevanilla.ru должен быть куплен/подконтролен тебе. Этот пакет не регистрирует домен и не публикует сайт автоматически.
- Статус и онлайн игроков не показываются, потому что для них нужен доступный API мониторинга сервера. Не отображаем выдуманные значения.
- Перед запуском замени шаблонные правила и команду на утверждённые сведения.
- Это статический сайт; для редактируемой панели администратора с защищённым входом понадобится backend.
